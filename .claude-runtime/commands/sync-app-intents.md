# /sync-app-intents — cmp-app-intents Sync

Verify-gated sync of `cmp-app-intents` into a consuming KMP app.
Gate 1: Gradle dependency. Gate 2: N/A. Gate 3: N/A (zero-config Gradle; Swift bridge and
Android App Actions XML are platform responsibilities documented in SETUP.md Steps 3–4).

---

## Module Contract (update when library changes)

```yaml
module:    cmp-app-intents
artifact:  io.github.mobilebytelabs:cmp-app-intents
version:   3.2.11
package:   com.mobilebytelabs.kmptoolkit.appintents
supabase:  false
di:        false   # no DI module — AppIntents.register() at app startup
nav:       false   # no nav destinations
config:    none    # zero Gradle config; Swift bridge = developer responsibility

api:
  - AppIntents.register(config: AppIntentsConfig)
  - AppIntents.invokeForTesting(id: String, params: Map<String, Any>): AppIntentResult?
  - appIntents { ... }: AppIntentsConfig
  - AppIntentsBuilder.intent(id: String) { ... }
  - AppIntentBuilder.title(text: String)
  - AppIntentBuilder.param(name: String) { type = ParamType.X }
```

## Gate 1: Gradle

### Check
```
1. Glob: gradle/libs.versions.toml
   → search "cmp-app-intents"
   → if found: verify version = 3.2.11
   → if missing or wrong: mark for fix

2. Glob: **/build.gradle.kts (KMP shared module)
   → search "cmp.app.intents"
   → if missing: mark for fix
```

### Fix
```toml
# libs.versions.toml [versions]
cmp-app-intents = "3.2.11"

# libs.versions.toml [libraries]
cmp-app-intents = { module = "io.github.mobilebytelabs:cmp-app-intents", version.ref = "cmp-app-intents" }
```
```kotlin
// build.gradle.kts commonMain.dependencies
implementation(libs.cmp.app.intents)
```

---

## Gate 2 + Gate 3: Not Applicable

`cmp-app-intents` is zero-config at the Gradle level:
- No Supabase backend
- No DI module (AppIntents.register() at app startup, no Koin wiring needed)
- No nav destinations

Platform bridge responsibilities (NOT auto-verified):
- **iOS/macOS**: copy `CmpAppIntentBridge.swift` into Xcode target — SETUP.md Step 4
- **Android**: `shortcuts.xml` is auto-generated by Gradle plugin — no manual step

After Gate 1 passes, sync is complete.
